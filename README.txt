ShiluVIP UDID Website

1) ارفع جميع الملفات إلى استضافة تدعم PHP.
2) افتح index.php من Safari على الآيفون.
3) اضغط تحميل ملف استخراج UDID.
4) ثبّت الملف من الإعدادات > تم تنزيل ملف التعريف.
5) بعد التثبيت سيُرسل الجهاز UDID إلى process.php ويظهر في صفحة النتيجة.

مهم: لا تستخدم استضافة ثابتة مثل GitHub Pages أو Cloudflare Pages لهذا الإصدار، لأن استخراج UDID هنا يحتاج PHP endpoint لاستقبال POST من Apple.
